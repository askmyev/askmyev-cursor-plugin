# AskMyEV for Cursor

Connects Cursor to [AskMyEV](https://askmyev.com), a hosted MCP server for your own Tesla's data: battery, range, charging sessions, tire pressures, alerts and saved history.

- Remote server: `https://askmyev.com/mcp` (Streamable HTTP, OAuth 2.1 with PKCE). You sign in on Tesla's own page the first time Cursor connects.
- Read-only by default. Location and car controls stay off unless you turn them on yourself in your AskMyEV account page.
- Free one-time health check. Daily history and watch are $4.99/mo or $39/yr, first month free.

Setup guide: https://askmyev.com/setup/ · Privacy: https://askmyev.com/privacy/ · Support: support@askmyev.com
